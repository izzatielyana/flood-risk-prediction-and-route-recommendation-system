# Requirements

## Functional requirements (what the system must DO)
FR1: The system shall predict flood risk levels for every 30 minutes using available data and historical flood data.
FR2: The system shall display the flood-prone areas information by using an interactive flood risk map.
FR3: The system shall send alert notifications to the users when the user’s location has a possibility of flood risk.
FR4: The system shall suggest an alternative route when the certain roads affected by the flood.
FR5: The system shall display the nearby relief centre based on user’s location.
FR6: The system shall allow users to submit flood reports by providing the location, description and an optional photo of the affected area.

## Non-functional requirements (how the system must PERFORM)
NFR1: The system shall display the flood risk map within a maximum 3 seconds under normal network conditions.
NFR2: The system shall request the user’s permission before accessing their current location.
NFR3: The system shall display the timestamp of the latest available flood data for each flood result.
NFR4: The system shall not store the user’s exact location history unless they have given specific approval.
