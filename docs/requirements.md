# Requirements

## Functional requirements (what the system must DO)
1. The system shall predict flood risk levels for every 30 minutes using available data and historical flood data.
2. The system shall display the flood-prone areas information by using an interactive flood risk map.
3. The system shall send alert notifications to the users when the user’s location has a possibility of flood risk.
4. The system shall suggest an alternative route when the certain roads affected by the flood.
5. The system shall display the nearby relief centre based on user’s location.
6. The system shall allow users to submit flood reports by providing the location, description and an optional photo of the affected area.

## Non-functional requirements (how the system must PERFORM)
1. The system shall display the flood risk map within a maximum 3 seconds under normal network conditions.
2. The system shall request the user’s permission before accessing their current location.
3. The system shall display the timestamp of the latest available flood data for each flood result.
4. The system shall not store the user’s exact location history unless they have given specific approval.
