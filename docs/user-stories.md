# User Stories

## User Story 1
As a user, I want to view flood-risk information for a selected area, so that I can understand the potential flood risk in that area.

### Acceptance Criteria
- Given the user selects an area, when flood-risk data is available, then the system displays the flood-risk information for that area.
- Given the user selects an area, when flood-risk data is unavailable, then the system informs the user that the data is unavailable.

## User Story 2
As a user, I want to view flood-risk predictions for the next 30 minutes, so that I can prepare for possible flooding.

### Acceptance Criteria
- Given flood prediction data is available, when the user views the prediction, then the system displays the predicted flood risk for the next 30 minutes.
- Given flood prediction data is unavailable, when the user requests a prediction, then the system informs the user that the prediction is unavailable.

## User Story 3
As a user, I want to view flood-risk information on an interactive map, so that I can easily identify areas that may be affected by floods.

### Acceptance Criteria
- Given flood-risk data is available, when the user opens the interactive map, then the system displays the flood-risk information on the map.
- Given the user selects an area on the map, when information for that area is available, then the system displays the relevant flood-risk information.

## User Story 4
As a road user, I want to receive alternative route recommendations, so that I can avoid flood-affected areas when travelling.

### Acceptance Criteria
- Given a route is affected by flooding, when an alternative route is available, then the system recommends an alternative route to the user.
- Given no alternative route is available, when the user requests an alternative route, then the system informs the user that no alternative route is available.

## User Story 5
As a user, I want to view rainfall and relevant flood data, so that I can make better decisions before travelling or leaving my home.

### Acceptance Criteria
- Given rainfall and flood data are available, when the user opens the relevant information, then the system displays the available rainfall and flood data.
- Given rainfall or flood data is unavailable, when the user requests the information, then the system informs the user that the data is unavailable.
