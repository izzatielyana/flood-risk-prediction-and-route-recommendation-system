# User Stories

Format: As a [type of user], I want [goal], so that [reason or benefit].

1. As a user, I want to view flood-risk information for a selected area, so that I can understand the potential flood risk in that area.
2. As user, I want to view flood-risk predictions for the next 30 minutes, so that I can prepare for possible flooding.
3. As a user, I want to view flood-risk information on an interactive map, so that I can easily identify areas that may be affected by floods.
4. As a road user, I want to receive alternative route recommendations, so that I can avaoid flood-affected areas when travelling.
5. As a user, I want to view rainfall and relevant flood data, so that I can make better decisions before travelling or leaving my home.
