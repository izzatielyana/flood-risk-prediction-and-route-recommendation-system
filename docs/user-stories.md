# User Stories

## User Story 1
- As a resident, I want to view flood risk levels on a map, so that I can identify areas that may be affected by the floods. (FR2)

### Acceptance Criteria
- The map displays flood risk levels using different colours.
- The system shall display the flood risk level when users select a location.

## User Story 2
As a road user, I want to get an alternative route when my usual route affected by the floods, so that I can avoid the flood risk. (FR4)

### Acceptance Criteria
1. The system shall identify road that affected by the flood.
2. The system displays an alternative route when a suitable route is available.

## User Story 3
As a resident, I want to find the nearby evacuation centres so that I can evacuate safely and be in the suitable and right place. (FR5)

### Acceptance Criteria
- The system displays an available nearby evacuation centres based on user’s location.
- The system shall give directions for users to a selected evacuation centre.
