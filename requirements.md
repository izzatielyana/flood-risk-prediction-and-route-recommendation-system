# Requirements

## Functional requirements (what the system must DO)
1. The system shall allow students to view flood-risk information for a selected area.
2. The system shall predict flood-risk levels for the next 30 minutes using available data.
3. The system shall display flood-risk information to an interacive map.
4. The system shall recommend alternative routes to help users avaoid flood-affected areas.
5. The system shall allow users to view rainfall inforation and relevant flood data.

## Non-functional requirements (how the system must PERFORM)
1. The system shall display tthe requested inforamtion within 5 seconds under normal operating conditions.
2. The system shall provide a simple and user-friendly interface that is easy to understand and navigate.
3. The system shall dsiplay an appropriate message when flood data is unavailable or cannot be retrieved.
